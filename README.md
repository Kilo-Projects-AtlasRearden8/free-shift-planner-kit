# Free Shift Planner Kit

Printable shift planners for nurses and shift workers: brain sheets, sleep logs,
handoff templates, and weekly schedules. Large-print friendly, no account needed,
no sign-up, no tracking.

**Published by Asdale Dynamics, LLC** — beginner-friendly AI education, books,
and practical tools. Find more at dylanasdale.github.io.

## What's inside

| Planner | File | For |
|---|---|---|
| Brain Sheet (shift report sheet) | `planners/brain-sheet.html` | End-of-shift patient summary and handoff notes |
| Sleep Log | `planners/sleep-log.html` | Track sleep, shifts, caffeine, and rest across a week |
| Handoff Template (SBAR) | `planners/handoff-template.html` | Structured Situation-Background-Assessment-Recommendation handoffs |
| Weekly Schedule | `planners/weekly-schedule.html` | Large-print week-at-a-glance shift and sleep planner |

Each planner lives in Markdown (`planners/*.md`) and as print-ready HTML
(`planners/*.html`).

## How to use

1. Open any `planners/*.html` file in your browser.
2. Print it (Ctrl+P / Cmd+P). Choose "Background graphics" if you want the
   shaded boxes; otherwise print black on white.
3. Fill it in by hand. Large print (16 pt base, bigger checkboxes and headings)
   and wide writing spaces make these easy to use on a unit or at home.

No account, no email, no data collection. Nothing you write in these pages is
sent anywhere — they run entirely in your browser.
